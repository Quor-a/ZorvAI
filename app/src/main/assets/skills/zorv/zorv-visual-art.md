# 美术指导（ZorvAI）

界面"土"通常不是组件问题，是**美术决策**没做。这一份管审美。

---

## 一、配色：先定方案，再选色

不要凭感觉挑颜色。先确定**配色方案**，再往里填：

| 方案 | 结构 | 效果 | 适合 |
|---|---|---|---|
| 单色（Monochrome） | 一个色相的深浅变化 | 极简、专业、安全 | 工具、后台、金融 |
| 类比（Analogous） | 色轮相邻 2~3 色 | 和谐、柔和 | 内容、阅读、生活 |
| 互补（Complementary） | 色轮相对两色 | 强烈、有张力 | 促销、运动、游戏 |
| 三角（Triadic） | 色轮等距三色 | 丰富、活泼 | 教育、儿童、创意 |
| 分裂互补 | 一色 + 补色两侧 | 平衡又有对比 | 通用首选 |

**饱和度与明度**：
- 大面积用**低饱和**（背景、卡片）
- 小面积用**高饱和**（按钮、关键数字）
- 高饱和大面积 = 廉价感

**中性色是骨架**：一个界面好不好看，80% 取决于中性色（白/灰/黑）用得干不干净，而不是强调色多炫。

## 二、视觉层次：让人 3 秒看懂

从上到下的注意力顺序，靠三件事控制：

1. **大小**：最重要的最大。标题至少比正文大 6sp。
2. **对比**：最重要的对比最强（深色底上的白字、大片浅色中的一点深色）。
3. **位置**：左上角和屏幕中部最先被看到。

**层级不超过 3 级**：主信息 → 次信息 → 辅助信息。层级太多 = 没有层级。

## 三、留白：空不是浪费，是设计

- **留白要成组**：相关元素靠近（4~8dp），不相关元素拉开（16~24dp）。
- **边界留白要够**：卡片内边距至少 12dp，页面边距至少 16dp。
- **不要均匀留白**：均匀分布 = 没有重点。重要内容周围留更多白。
- **留白要有理由**：不是为了填满而撑高的空白，是错的（那是空洞，不是留白）。

## 四、质感：阴影、渐变、圆角的克制用法

- **阴影**：只给"浮起来的东西"（卡片、浮层、按钮）。**一个界面最多 2 级阴影**。
- **渐变**：要么用在**大面积背景**（轻微，同色系），要么用在**强调元素**（按钮、进度条）。不要给每个卡片加渐变。
- **圆角**：同一层级的元素圆角必须一致。混用 4 和 16 会显得拼凑。
- **边框**：浅色底用浅边框（1px），深色底用微亮边框。**不要边框+阴影同时上**。

## 五、图标与装饰：少即是多

- **同一屏图标风格统一**（全部线性或全部填充，不要混）。
- **emoji 当作彩色图标用**，一屏最多 2~3 个做点睛；**不要每个条目都挂 emoji**（廉价）。
- **装饰元素（渐变球、光晕、纹理）**要么不用，要用就在背景层大面积铺，不要小面积点缀。
- **不要用装饰掩盖布局问题**：内容没排好，加多少装饰还是丑。

## 六、图像

- 没有真实图片时，用**纯色块 + 图标**占位，不要用花哨的占位图。
- 图片上盖文字必须加**半透明遮罩**或**渐变层**，保证文字可读。
- 头像/封面统一**圆角与比例**（1:1 或 16:9），不要混。

## 七、风格一致性检查

生成后问自己三个问题：

1. **这套配色是不是只有 1 个强调色？**（超过 2 个 → 花）
2. **所有卡片是不是同一套圆角/底色/阴影？**（不一致 → 拼凑）
3. **去掉所有颜色，靠黑白灰还能不能分清主次？**（不能 → 层次只靠颜色撑，脆弱）

三个都通过，才是真的"有设计感"。

## 风格速查（需要具体色值时配合 `zorv-design-systems` 使用）

| 想要的感觉 | 方向 |
|---|---|
| 专业 / 可信 | 低饱和蓝 + 大留白 + 小圆角 |
| 高级 / 奢侈 | 暗底 + 哑光金 + 衬线细字 + 极大留白 |
| 活泼 / 亲和 | 高饱和绿/橙 + 大圆角 + 粗字重 |
| 科技 / 未来 | 暗底 + 靛蓝/青 + 细边框 + 等宽字体 |
| 温暖 / 人文 | 米色底 + 赭红 + 衬线标题 |
| 极简 / 克制 | 纯黑白 + 无彩色 + 靠字重和间距分层 |
