# 设计系统速查（ZorvAI GenUI）

提炼自 **151 套品牌级设计系统**的通用规律。写界面时**直接引用下表**，不要凭感觉编颜色 —— 自己编的配色十有八九是"脏"的。

---

## 通用规范（所有风格都遵守）

**间距**（8pt 网格）：`4 / 8 / 12 / 16 / 24 / 32`。不用 5、7、13 这种散值。

**圆角**：
| 元素 | 圆角 |
|---|---|
| 卡片 / 面板 | 12~16 |
| 按钮 | 8~12（胶囊按钮用 999） |
| 输入框 | 8 |
| 标签 / chip | 999（胶囊） |
| 头像 | 999（正圆） |

**阴影**（elevation）：卡片 2，浮层 4，对话框 8。**不要给文本加阴影**。

**字号阶梯**：标题 20 / 小标题 16 / 正文 14 / 辅助 12 / 角标 10。一级之差至少 2sp。

**60-30-10 配色法则**：主色占 60%（背景/大面积）、辅助色 30%（卡片/次要）、强调色 10%（按钮/关键信息）。

## 字体配对

| 风格 | 标题 | 正文 |
|---|---|---|
| 通用 / 系统 | `sans-serif` 中黑 | `sans-serif` 常规 |
| 科技 / 数据 | 等宽或几何无衬线 | 无衬线，字重偏细 |
| 杂志 / 人文 | 衬线 | 无衬线（易读） |
| 高端 / 奢侈 | 衬线，字重轻，字距宽 | 无衬线小字 |
| 亲和 / 教育 | 圆体 / 粗无衬线 | 圆体 |

**中文场景**：标题可用字重 `Bold(700)` 制造对比；正文保持 `Normal(400)`；**中文字号不要小于 12sp**。

---

## 使用方式

1. 用户没说风格 → 用 **Neutral Modern**。
2. 用户说了场景（"做个音乐播放器"）→ 选对应风格（Spotify）。
3. 用户说了感觉（"高级一点"）→ **Luxury**；"温暖" → **Warm Editorial**；"专业" → **Stripe**。
4. 选好风格后，**严格照抄色值**，不要临场调。混搭两套风格 = 脏。

**配色一致性检查**：一屏内强调色只能有 **1 个**（最多 2 个），其余全是中性色。
