# 数据分析

## 🔴 分析前必须先问清（不许猜）

| 问题 | 为什么必须问 |
|---|---|
| **口径**：这条指标怎么定义的？ | 「活跃用户」= 登录过 / 有操作 / 停留>10s，口径不同差 3 倍 |
| **粒度**：按什么维度拆？时间/地区/渠道？ | 决定能得出什么结论 |
| **时间范围**：哪个区间？同比还是环比？ | 环比可能只是季节波动 |
| **数据完整性**：有无缺失、缺失是否随机？ | 缺失非随机时结论直接失效 |
| **样本量**：多少条？ | n<30 的均值没有意义 |

**问不到就明说「口径不明，以下分析基于假设 X」**，不要默默按最常见口径算。

## 铁律

- ❌ **不做无数据的断言**。每个数字后面都能指出是怎么算出来的。
- ❌ **不把相关当因果**。相关只能写「A 与 B 同时升高」，不能写「A 导致 B」。
- ❌ **不选择性呈现**。基线、对照组、反例都要给。
- ❌ **不报没有不确定性区间的点值**。给了均值就要给波动范围。
- ❌ **不忽略缺失值**。丢了多少行、丢在哪、为什么丢，必须写出来。
- ❌ **不把小样本当结论**。n<30 一律标「样本不足，仅供参考」。

## 工作流

1. **问口径**（上表五问）。
2. **先看数据本身**：行数、列类型、缺失率、重复行、异常值。
   **先看分布，再谈任何关系。** 直接跑相关分析是最常见的错误顺序 ——
   两列趋势性数据（例如都随时间增长）能算出高相关，但毫无意义。
4. **清洗并记录清洗动作**：删了哪些行、改了哪些值，每步计数。
5. **分析**：分组对比 → 看分布 → 检验关系。相关性检验前先做去趋势。
6. **给结论 + 局限**：结论是什么、有什么不能下的结论、数据本身的缺陷。

## 报告必须包含

- **口径说明**（怎么定义的）
- **数据概况**：N 行、缺失率、时间范围
- **清洗动作清单**（改了什么）
- **发现**，每条附数据（不是「略有上升」，是「从 3.2% 到 4.1%，+0.9pp」）
- **不能下的结论**（样本不足 / 口径不明 / 存在混淆变量）
- **建议**，标清是基于哪条发现

## 数字写法

| 别写 | 改成 |
|---|---|
| 大幅上升 | 从 3.2% 升至 4.1%，+0.9pp |
| 明显更高 | 均值 12.3 vs 8.7（n=240/180，p<0.01） |
| 相关性很强 | r=0.72（已去时间趋势） |
| 大约一半 | 47.8%（n=1200） |

**每个数字要么给 n，要么给区间，要么给误差。**

## 自检清单

- [ ] 五问（口径/粒度/时间/完整性/样本量）已问或已标为假设
- [ ] 已先看分布，再谈关系
- [ ] 缺失率已计算，缺失是否随机已判断
- [ ] 清洗动作逐条记录（删改各多少行）
- [ ] 相关性分析前已做去趋势/分组
- [ ] 未把相关写成因果
- [ ] 每个数字给了 n / 区间 / 误差之一
- [ ] 基线与对照组已给出
- [ ] 「不能下的结论」这一节已写
- [ ] 小样本处已标「样本不足」

## 交付时说清

口径、数据量、清洗做了什么、最重要的三条发现、以及**明确不能下的结论**。
最后一条最容易被省，也最重要。
