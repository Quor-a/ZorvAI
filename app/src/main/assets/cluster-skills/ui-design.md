# 界面设计

## 开工前先把规格写下来

**没有规格就不要画。** 先输出这份规格表，规格表本身就是交付物的一部分：

| 项 | 必须写清 | 判据 |
|---|---|---|
| 主色 | 1 个，HEX | 只允许 1 个 |
| 语义色 | 成功/警告/危险，各 1 个，HEX | 恰好 3 个 |
| 灰阶 | 5 级，HEX | 恰好 5 级，含背景/次级背景/边框/次要文字/正文 |
| 字号阶梯 | 4~5 级，每级标 px 与行高 | 比例接近 1.25，不是随意取值 |
| 间距刻度 | 只用 4/8/12/16/24/32/48 | 出现刻度外的数值就是错 |
| 强调色用量 | 全页 ≤3 处 | 数出来 |
| 栅格 | 一套，所有区块对齐它 | 不许有的区块 12 列有的 8 列 |

## 🔴 明令禁止的 AI 通用脸

以下这套组合**一律禁止**，出现任何一条即为不合格：

- ❌ **紫蓝渐变**（indigo→violet、purple→blue 那类 #6366F1/#8B5CF6 打底渐变）
- ❌ **统一大圆角**（所有元素一律 12px/16px/999px，不分层级）
- ❌ 玻璃拟态糊一切 + 霓虹发光描边
- ❌ 满屏 `linear-gradient(135deg, ...)` 背景
- ❌ 「深色 + 紫粉高光」通用 SaaS 脸
- ❌ 三个卡片高度全等、阴影全同、图标全同色

**为什么禁**：这套组合是训练数据里出现频率最高的通用答案，它不携带任何关于「这是给谁用的」的判断。用它 = 没做设计 = 让用户自己去猜需求。

**替代要求**：配色必须从**内容本身**推出来 —— 品牌色、目标用户所在行业的语义色、数据本身的色相。
推不出来就明说「缺品牌色，需要指定」，不许退回通用渐变。

## 层级怎么拉开（替代「统一圆角」的正确做法）

| 层级 | 圆角 | 阴影 | 说明 |
|---|---|---|---|
| 容器 | 大（12~16px） | 有 | 承载区块 |
| 内容块 | 中（6~8px） | 轻 | 卡片、内部面板 |
| 控件 | 小（4~6px） | 无 | 按钮、输入框 |
| 标签/胶囊 | 全圆（999px） | 无 | 仅用于状态标签 |

规则：**圆角随元素在层级中的位置递减**，不随个人偏好。

## 字号阶梯（用就照抄，别自己编）

| 角色 | px | 行高 |
|---|---|---|
| 主标题 | 28~32 | 1.25 |
| 副标题 | 20~24 | 1.3 |
| 正文 | 15~16 | 1.6 |
| 辅助文字 | 13~14 | 1.5 |
| 标签/注释 | 12 | 1.4 |

## 工作流

1. **问清三件事**（缺哪件就问，不许猜）：给谁用、在什么场景用、有没有品牌色/既有配色。
2. **写规格表**（上面那张表），先给数字，再谈美观。
3. **定层级**：把界面元素按 容器/内容块/控件/标签 分四层，每层定圆角与阴影。
4. **只用一个强调色**，且全页 ≤3 处。
5. **眯眼测试**：把图缩到 15% 看，如果主标题、正文、按钮三类元素还能一眼分开，说明层级成立；
   分不开就是层级没拉开，回去改层级，不是改颜色。
6. **对齐检查**：所有区块落在同一套栅格上。

## 自检清单

- [ ] 规格表已输出：主色 1 + 语义色 3 + 灰阶 5，全部是 HEX
- [ ] 字号阶梯 4~5 级，每级标了 px 与行高
- [ ] 间距全部落在 4/8/12/16/24/32/48 内（逐个查，出现别的值就改）
- [ ] 强调色全页出现 ≤3 处（数出来）
- [ ] **零紫蓝渐变**（逐处检查 135deg 渐变与 #6366F1/#8B5CF6 类底色）
- [ ] 圆角按层级递减，不是全场一个值
- [ ] 眯眼测试通过：三类元素仍可分辨
- [ ] 所有区块对齐同一套栅格
- [ ] 配色来源是内容/品牌/数据，不是通用模板

## 交付时说清

给了哪些 HEX、用了哪套字号、间距刻度是什么、强调色用在哪 3 处。
说不出这些数字 = 没做设计。
