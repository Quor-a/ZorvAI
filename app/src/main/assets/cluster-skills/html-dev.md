# 单文件 HTML 开发

## 硬约束（以下每条都是**硬**的，不是建议）

❌ 不许输出需要构建才能跑的东西（npm / vite / webpack / 任何编译步骤）。
❌ 不许引外链字体、CDN 图标库 —— 断网或内网环境下页面会直接塌。
❌ 不许用 `fetch()` 读本地文件、不许跨文件 ES module import（`file://` 下直接失效）。


- **一个文件**。HTML + CSS + JS 全部内联。
- **零构建**。不许出现 npm / vite / webpack / 任何需要编译的步骤。
- **零外链**。不许 `<link href="https://fonts.googleapis.com">`、不许 CDN 上的图标库、不许外链字体。
  原因：断网或用户在内网时页面直接塌。图标用内联 SVG 或 Unicode。
- **双击即开**：`file://` 协议下必须正常工作。不许用 `fetch()` 读本地文件、不许 ES module 的跨文件 import。
- 外部数据只用 `<script src="...">` 或图片链接，允许，但不许是「页面能不能开」的前提。

## 工作流

1. **先写结构**：语义标签（`header/nav/main/section/footer`），不为了省事全用 `div`。
2. **再写样式**：CSS 变量集中在 `:root`，间距只用固定刻度（4/8/12/16/24/32/48）。
3. **再写交互**：原生 JS，无框架。事件用 `addEventListener`，不许内联 `onclick` 字符串。
4. **响应式**：至少断 375px / 768px / 1200px 三档。移动端不许出现横向滚动条。
5. **跑自检清单**（下面那份），逐条点。

## JS 部分的硬要求

- 所有 `querySelector` 结果都要判空再用，否则静态页面改一行就崩。
- 事件监听绑在容器上用委托，不要给每个子元素单独绑。
- 不许用 `localStorage` 存敏感信息；用了要说明用途。
- 内联 SVG 必须带 `viewBox` 和 `aria-hidden="true"`（装饰性）或 `role="img"` + `<title>`（有意义）。

## 自检清单（打开页面逐条点，不许凭印象打勾）

- [ ] 双击打开，无报错、无白屏
- [ ] F12 控制台 **0 error**（warning 可接受，但要在交付里说明）
- [ ] 375px 宽度下无横向滚动条
- [ ] 768px / 1200px 下布局不塌（内容不重叠、不溢出容器）
- [ ] 断网后重新刷新，页面仍能正常显示（无外链资源变叉）
- [ ] 所有 `querySelector` 结果有判空
- [ ] 间距值全部落在 4/8/12/16/24/32/48
- [ ] 交互元素（按钮/链接）有 hover 与 focus 态，键盘 Tab 能走到
- [ ] 图片有 `alt`（装饰性图片写 `alt=""`）
- [ ] `<title>` 已填，不许是「文档」或文件名

## 交付时说清

文件路径、多少行、控制台有无 error、测过哪几个断点。
没实际打开过就不许说「已完成」。
