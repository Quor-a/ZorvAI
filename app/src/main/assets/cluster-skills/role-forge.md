# 角色锻造（主持专用）

## 什么时候用

**技能装够了、能力仍然没人覆盖**，才造新角色。
如果本地已有角色沾边但判据不清，正确做法是**改那张卡**（补 soul 的可判据标准），不是再造一个。

## 不许做的事

- ❌ 不许造「你是一个专业的 XX」这种空壳。那句话没有约束力，模型只能按训练时的通用知识猜，每次输出都不一样。
- ❌ 不许造多于一张。一次最多造一张。
- ❌ 不许把新角色定成 HOST，也**绝不能**定成 CRITIC 之外还带执行权的评审（评审不碰工具）。
- ❌ 不许造卡时不写 soul。soul 是这张卡唯一能判定对错的部分。
- ❌ 不许因为「顺手」把新卡塞进所有节点。它只服务于那个能力缺口。

## 建卡流程

1. **先复查一遍能力自查**：确认不是「本地有角色沾边但判据不清」。
   是的话改那张卡（补 soul 的可判据标准），停止造新卡。
2. **写 tagline**：一句话说清它是谁，必须能回答「为什么不用已有角色」。
3. **写职责** 3~5 条，每条是「动作 + 对象」。
4. **写 soul 三段**：beliefs（断言）/ despises（拒绝什么）/ standards（**可判据**）。
5. **定 kind**：要动手 = EXECUTOR；只判断 = CRITIC；出方案不下手 = PLANNER。
6. **绑技能** 1~3 个，逐个核对是否覆盖了缺口描述里的全部关键名词。
7. **立刻重跑能力自查**（见文末）。有覆盖才算成。
8. **回报**：它是谁、接哪一单、少了什么。

## 四段式人格卡（缺一段就不许建卡）

### 1. 身份与一句话说明
`tagline`：一句话说清它是谁，给主持看，决定要不要点名它。
必须能回答「为什么不用已有角色」。

### 2. 职责（3~5 条，每条是一个动作）
写「做什么」，不写「擅长什么」。
✅「把需求拆成可验收的子节点」
❌「擅长规划」

### 3. 灵魂 soul（三段，缺一不可）

- **信念 beliefs**：它凭什么下判断。2~4 条，每条是断言，不是形容词。
  例：「没有验收标准就不动手，宁可回去问。」
- **鄙视什么 despises**：它拒绝什么样的产出。2~4 条。
  例：「拒绝给出无法验证对错的『大概可以』。」
- **什么叫做好 standards**：**这一段必须是可判据**。
  每条要能被「看/数/查」判定，不允许出现「美观」「高级」「专业」这种纯形容词。
  ✅「主色 1 个 + 语义色 3 个 + 灰阶 5 级，全部写出 HEX」
  ✅「验收标准必须能写成一条 if-then 测试」
  ❌「视觉要有质感」

### 4. 技能绑定
1~3 个，写清每个技能**覆盖的是哪个名词**。
绑完要确认：这些技能合起来是否真的覆盖了缺口描述里的关键名词。

## 自检清单

- [ ] tagline 能回答「为什么不用已有角色」
- [ ] 职责是动作（3~5 条），不是能力形容词
- [ ] soul 三段齐全，beliefs/despises/standards 各自非空
- [ ] standards 每条可被看/数/查判定，无纯形容词（逐条自查）
- [ ] 绑定的技能覆盖缺口描述里的全部关键名词（逐个核对）
- [ ] kind 选对了：要动手 = EXECUTOR，只判断 = CRITIC，**评审不绑任何执行工具**
- [ ] 建卡后立即回报：它是谁、接哪一单、少了什么

## 造完立刻自检的第一个问题

「主持自查：有没有人具备该能力？」
新卡建完要重跑一次自查。有覆盖 → 才算成；还是没覆盖 → 如实说「这单没有合适的人」，标记跳过，不要死循环造第二张。
