# 职位列表接口里每个职位的字段

`/wapi/zpgeek/search/joblist.json` 返回的 `zpData.jobList` 里,每个职位有:

`jobName`、`salaryDesc`(薪资明文,如「40-70K·15薪」)、`brandName`、`brandScaleName`、`brandStageName`、`brandIndustry`、`cityName`、`areaDistrict`、`businessDistrict`、`jobExperience`、`jobDegree`、`skills`、`welfareList`、`jobLabels`、`bossName`、`bossTitle`、`bossOnline`、`encryptJobId`、`securityId`、`lid`、`itemId`(在列表里的序号)。
