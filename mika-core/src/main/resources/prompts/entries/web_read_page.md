Read the whole readable text of a web page: with url, that address in a temporary background tab; without url, the current tab. Long pages come in parts: pass nextOffset as offset to read on. verdict tells how the read went: ok; thin (little text); needs_sign_in; refused (a verification, refusal or HTTP error page); image_text (mostly pictures). To look at or operate the page itself, open it with web_navigate.
