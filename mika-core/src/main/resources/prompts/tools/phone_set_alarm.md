Set an alarm in the phone's clock app through the standard Android alarm action, without opening its screens: one call per alarm (for several alarms, call it once for each time). The time is the 24-hour local hour and minute; days makes it repeat on those weekdays. The result says which app took it (handledBy) and check: verified means the system now reports this as the next alarm, so it is set; earlier_alarm_first means an earlier alarm comes first, so this one cannot be seen from here; not_seen or unknown means it could not be confirmed. Only when the user needs certainty and check is not verified, call phone_show_alarms once and observe the list. If it returns not_supported, set the alarm in the clock app's own screens instead. This is a phone alarm; schedule_task is for Mika's own scheduled tasks and reminders.
