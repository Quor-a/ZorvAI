Open a page directly on the virtual display instead of tapping through the app. Give action for an Android settings page (one of: {{settings_actions}}; {{app_details}} also needs uri package:<package name>), or uri for a link listed in the reference notes (a web link also needs package, the app that should open it). File, content, intent and javascript links are unsupported; phone, SMS and mail links can open their apps when listed in the reference notes. If it returns link_unresolved, use phone_launch_app and navigate instead. Actions on the opened page are checked as usual.
