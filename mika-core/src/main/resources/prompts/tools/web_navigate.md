Open a web page (http or https only) in Mika's built-in browser; the web_* screen tools (web_observe, web_tap, web_type_text, web_scroll, web_back, ...) then act on it. Waits up to 20 seconds for the page to load (loaded=false: still loading, web_observe again). Returns tabId, the final url, title and httpStatus. If the page cannot be opened, it returns ok:false with the browser's error code (netError, e.g. net::ERR_NAME_NOT_RESOLVED); an http address the phone refuses as plain text is tried once over https. If the address turns out to be a file, it is downloaded instead and the result says so with the download's status.
