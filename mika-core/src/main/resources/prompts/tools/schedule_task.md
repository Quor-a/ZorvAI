Create or manage this user's scheduled tasks. Use op=list to inspect existing plans before changing one; use its triggerId for pause, resume, delete, run_now or reschedule. With op=create (default), schedule a future task only when the user asks you to do something later. For a fixed reminder, set reminder to the exact message and goal to its short description; this delivers without running a model. For work that needs app or web operations, omit reminder. Use at for a one-time or fixed-interval start; use repeatAt with repeatZone and optional weekdays for a daily/weekly local clock time, so daylight-saving changes do not shift the clock time. A condition is checked first with read only web and sandbox tools; the task runs only if the condition becomes met. Set whenIdle when the user wants the task to wait for an idle period after that time. Do not claim that a future task is arranged until this tool succeeds.
