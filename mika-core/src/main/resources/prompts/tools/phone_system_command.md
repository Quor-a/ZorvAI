Run an Android shell command through this task's connected shell helper, with shell UID permissions. This is the device shell, not the Linux sandbox. The command has a 10 second timeout and bounded output. The MIKA_DISPLAY_ID environment variable identifies this task's virtual display; include it in commands that inject UI input, for example input -d "$MIKA_DISPLAY_ID" tap 500 800. Do not use it to tap, type, press keys, open apps or share text when a phone tool can: those act on Mika's screen and check the result, shell input does not. The first such command runs with a hint naming the right tool; after that, such commands are refused (error use_phone_tool), and text shares (am start with a SEND intent) are always refused: use phone_share_text. Commands that read state or settings are not affected. If a command fails, do not keep trying variations of it.
