Open an installed app on the phone's virtual display by exact package name, and wait until it is in the foreground. To open another copy of the app (a clone or work-profile copy), also pass user from that copy's phone_list_apps entry; leave it out for the main app. Set cold=true to restart it from its initial screen. If the app does not reach the foreground, it returns ok:false with what is there instead; if it is in the foreground but its window cannot be read, the result says so: do not launch it again. If the system asks which one to open (an app installed twice, as main and clone), it returns ok:true with chooser: tap the option the user meant, otherwise the main one, and do not launch again.
