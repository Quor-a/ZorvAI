Run one of the current site's commands by name: a read-only script kept in the site's knowledge that pulls structured data out of the page you are on. The commands and their arguments are listed in that site's knowledge. It runs like web_evaluate_js (real page, read-only, same-origin GET requests only) and returns its result as JSON (at most {{result_max}} characters). Open the page the command is meant for first. unknown_command means the current site has no command by that name; the message lists the ones it has.
