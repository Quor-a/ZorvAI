Open the calendar app's new-event screen on the phone's virtual display with the title, time, place and notes filled in (the standard Android insert-event action; no calendar permission is used). Nothing is saved yet: observe the screen, check the fields, and tap its save button yourself, then check the result. start and end are local times like 2026-11-02T14:30; for an all-day event give the date like 2026-11-02 with allDay=true. If it returns not_supported, open the calendar app with phone_launch_app and add the event there.
