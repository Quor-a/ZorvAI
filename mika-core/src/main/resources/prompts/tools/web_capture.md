List the XHR/fetch responses the current tab received (newest {{list_max}}, without bodies), or pass id to get one with its body (JSON or text only, long bodies truncated). Useful when the page shows data loaded from an API: the JSON is often more complete than the screen, and it is where to read numbers the page draws garbled (custom fonts). Only read what the page itself loaded; do not send your own requests to the site's APIs. Recording starts the first time the page is acted on or this tool is used. Fails with devtools_unavailable when this phone's browser cannot record network traffic.
