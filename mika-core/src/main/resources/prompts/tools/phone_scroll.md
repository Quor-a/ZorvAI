Scroll in the Android app. direction=down shows content further down (the finger moves up for a gesture); up shows content further up (the finger moves down). With the default amount and no x/y, Mika first asks the scrollable accessibility node to move and falls back to a gesture if no such node is available. Give another amount (1-20) or x/y when you need a specific gesture or scroll region. Repeating a scroll can be correct when it reveals new content. Stop at the end only when the page state confirms there is no new content; effect.kind no_effect with atEnd is one signal.
