Read data from the current web page with JavaScript, and get the result back as JSON (default time limit {{default_seconds}} s, result at most {{result_max}} characters; values that look like credentials or tokens are masked). The script runs inside the real page and sees the live DOM, but it can only read: document, window, location and getComputedStyle are read-only views of the page (querySelectorAll, getAttribute, textContent, getBoundingClientRect and the like work; setting a property, adding or removing elements, click(), focus(), submit(), opening windows or navigating fail with read_only). Password, hidden, one-time-code and card fields read as ***, and cookies and local storage cannot be read. It cannot use the network: fetch, XMLHttpRequest, sendBeacon, WebSocket and loading images or scripts fail with blocked_network; it only reads what the page already has (to read data the page loaded from its APIs, use web_capture). Also available: sleep(ms), URL, URLSearchParams, plain JavaScript (JSON, Math, Array…), and state, an object that keeps what you put in it across calls on the same page (state="new" in the result means it was just created, e.g. after the page changed). script is one expression or the body of an async function that uses return; return plain data (strings, numbers, arrays, objects), not elements. To act on the page use the action tools.
