Look at the current web page. Returns the site (currentSite), url, title and tabId, and a fresh element snapshot (snapshotId + elements) of what is in view. A screenshot is added when the element list is clearly unreadable or mostly unlabeled. If the target is missing or ambiguous, request {{screenshot}} or {{find_visually}}. Prefer tapping a ref from this result with {{tap}} over guessing coordinates; to read the whole page, use web_read_page.
