Run a shell command in the Linux sandbox (Alpine, /bin/sh -lc) with /workspace as the working directory. Returns exitCode, timedOut, durationMs, the output (head and tail when long; then fullOutputPath has all of it) and whether the network is on. ok is true only when the exit code is 0 and it did not time out. `mika phone <op> '<json-args>'` calls the current task's phone tools through their normal execution path; for example, `mika phone query '{"text":"设置"}'` or `mika phone run '[{"op":"tap","targetText":"设置"}]'`. Use the direct phone tools for simple work to avoid starting a shell.
