Turn a wheel picker (the drums of a time, date, number or region picker; marked wheel:true in the tree when recognised) to a value in one call: pass the wheel's ref (or the ref of the item it shows now) and the value as written on it, e.g. 9, 40, 2026 or a name. The tool types the value when the wheel accepts text, otherwise steps or drags it there and reads it back itself, so do not swipe a wheel step by step. Call it once per wheel (hour, then minute); refs of the other wheels stay valid. The result gives value (what the wheel shows now), from, attempts and method. If ok is false, value is what it shows now: observe once and decide; an at-end error means the value is not on this wheel. A not-moving error means dragging the wheel had no effect: turn it yourself with phone_swipe on that wheel's column, a few items at a time, and read it back.
