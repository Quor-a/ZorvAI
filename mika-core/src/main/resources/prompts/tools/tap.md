A full-name match is used first; failing that, a name that starts with it, then (for tappable elements only) one that contains it, and then the result shows resolvedFrom and matched so you can check it was the one you meant. If several match, the result lists them (ref, place, nearby text) to pick from; if none, observe first. For a coordinate tap, say in target what you are tapping. Do not repeat an unchanged coordinate tap. clicks=2 double-taps (for things that open or zoom only on a double tap). The result's effect says what the action did to the interface: done (a clear change), small_change (only focus, a toggle or one or two elements changed, or it may still be loading: check it), no_effect (nothing in the interface changed: try another way instead of repeating) or place_changed (now somewhere else, given in effect.to).
