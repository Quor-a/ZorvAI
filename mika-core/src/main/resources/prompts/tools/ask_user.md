Ask the user a question when information is missing or a choice is theirs to make; add options when there are a few clear answers. Passwords and verification puzzles are not asked here: those go to hand_to_user, and only when the tools cannot do the step. The result holds the user's answer. If no answer comes in time you get error no_answer, which is not an answer: carry on with the most sensible reading and say so in your reply, or end_not_done if the task cannot continue without it.
