Read text across successive screens in the current Android app, scrolling locally between reads. Use for chat history, feeds, lists, and other long content. Choose the direction toward content you need. The tool merges overlapping lines and stops when no new text appears twice, the app changes, an action fails, or a resource limit is reached. Set fromY and toY to exclude fixed headers or bottom navigation when needed. Inspect the collected text and continue with another call if stopped by a limit. Each scroll is recorded as its own action. The app screen moves while collecting.
