Press a navigation or editing key on the current screen. Allowed: {{keys}} (by name or numeric keycode). Volume, power, home, recents, search, assistant, camera and media keys are rejected. The result's effect says what the action did to the interface: done (a clear change), small_change (only focus, a toggle or one or two elements changed, or it may still be loading: check it), no_effect (nothing in the interface changed: try another way instead of repeating) or place_changed (now somewhere else, given in effect.to).
