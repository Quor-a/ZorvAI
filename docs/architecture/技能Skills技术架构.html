技能 Skills 技术构架

ZorvAI / WorkBuddy · Skill 引擎

一、构架介绍

技能（Skill）是 WorkBuddy / ZorvAI 的「可复用专业能力包」：一段结构化的 SKILL.md + 可选的 scripts/、references/、assets/，在需要时由 Skill 工具加载进上下文，赋予主理人（Agent）领域知识与标准化工作流。

它的核心价值是把「某类任务怎么干」从模型记忆里外置成可版本化、可审计、可共享的工件，避免每次都靠 prompt 临时拼凑。当前会话可见 100+ 专家 / 技能（前端、安卓、区块链、文档、运维、设计等）。

设计三原则：

  • 两级作用域：用户级 ~/.workbuddy/skills/（跨项目）与项目级 {workspace}/.workbuddy/skills/（团队共享），互不污染。
  • 安装即审计：任何 install / import / download 的技能必须先过 skills-security-check，按 P0（致命）/ P1（警告）/ P2（安全）定级，P0 需用户显式确认方可落地。
  • 积累即沉淀：完成多步任务或修正 tricky 错误后，用 SkillManage 把可复用流程回写为新技能，形成正循环。

三、核心组件

组件职责关键点
SKILL.md技能定义文件，frontmatter 声明名称、描述、触发词、位置agent_created: true 仅模型自建技能可被 SkillManage 改
SkillManage创建 / 修改 / 删除 / 列出技能用户级优先，除非用户显式要求项目级
skills-security-check安装前安全审计输出 P0/P1/P2 风险，P0 须用户确认
find-skills检索并推荐可安装技能能力缺口时首调，禁止直接说「做不到」
expert-manager专家包全生命周期（转化 / 修改 / 合规 / 审查）与 Skill 互补，面向「角色型」能力

四、生命周期（Skill Lifecycle）

1发现：能力缺口 → find-skills 检索市场 / 本地
2安装：download / import → 先跑 skills-security-check 出 P0-P2 报告
3加载：命中触发词 → Skill 工具把 SKILL.md 注入上下文
4执行：按工作流调用 scripts / 工具 / 子流程
5反思：发现过时 / 错误 / 缺漏 → SkillManage(modify) 原地修正
6沉淀：完成 8+ 步任务或 tricky 修复 → 回写为新技能
