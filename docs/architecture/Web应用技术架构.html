Web 应用 技术构架

ZorvAI · MiniAppFramework（AI 生成 HTML/JS 内联渲染）

一、构架介绍

Web 应用是 ZorvAI 内「AI 生成即可运行」的可视化 Web 应用工作台。核心是 MiniAppFramework：把 LLM 产出的 HTML/JS 在应用内渲染容器中沙箱运行，支持同目录资源（图片自动转 data URI）、私有 app:// 协议、对话框内联预览与独立面板编辑。用户 / AI 可在 Web 应用面板新建、编辑、运行 Web 应用，无需打包上架。

它把「写代码」变成「对话即产物」：AI 生成 → 安全化写入工程目录 → 面板 / 对话框内联渲染 → 运行 / 分享，形成低门槛的可编程能力面，是 ZorvAI 工具生态的轻量扩展通道。

  • 内联渲染：HTML/JS 跑在应用内 WebView/内联容器，免安装、即写即跑。
  • 资源自包含：同目录图片在预览时转 data URI，与面板内 app:// 渲染一致，避免路径错位。
  • 安全写入：工程名 / 路径做安全化，防止 .. 越界写入工程目录外。
  • 双入口：对话框内联预览 + 独立 Web 应用面板编辑，互相打通。

四、关键流程（一次 AI 生成 Web 应用）

1发起：用户在 Web 应用面板「新建示例」或对话框请求 → AI 生成 HTML/JS
2校验：对工程名 / 路径做安全化，防止越界写入工程目录外
3写入：writeFlow 落盘到 Web 应用工程目录（含同目录资源）
4渲染：MiniAppFramework 内联渲染；预览时同目录图片转 data URI，app:// 资源定位一致
5运行 / 分享：面板或对话框内运行，支持导出 / 分享
