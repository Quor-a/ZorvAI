# 工厂 undo 退役迁移保留普通配置

退役归属比较曾把空查表结果和无 name 的普通行都当成 null，相等后误删普通行。现存结构校验正确拒绝整个结果，因此旧设备一直保留自动 undo。修复先要求退役清单明确声明 id，再比较包名。用户自建行和带配置的历史条目保持原有保留规则，不删除历史快照或归档。

启用正确迁移的同时，写盘复用已验证的快照原子文本发布：必须先同步保存唯一旧文本备份，再替换目标。发布失败保留旧文件并重试，不再回退为截断直写。结构校验继续有效。

新增 JVM 真实转换回归与 Android 独立缓存测试，覆盖普通无名条目、空退役表、用户配置保留及发布失败旧字节不变。设备实际升级结果在 PR 收口；未运行的验证不视为通过。
